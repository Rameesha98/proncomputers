PRO N COMPUTERS - STATIC WEBSITE

FILES
- index.html: website content
- style.css: design and responsive layout
- script.js: mobile navigation and copyright year
- assets/pro-n-banner.webp: hero banner image

IMPORTANT
1. Keep the assets folder beside index.html.
2. Add your two team photos into the assets folder using these exact names:
   - myphoto.png
   - kalhara.png
3. Open index.html in a browser to preview.
4. Upload all files and the assets folder to your web hosting public_html folder.

The website uses only red, white and black design colours.
The Google Fonts import requires an internet connection; the site still works with fallback fonts.
